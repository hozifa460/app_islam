## 📖 نبذة عن التطبيق

**تطبيق الإسلام** هو تطبيق Flutter متكامل صُمم ليكون رفيقًا يوميًا للمسلم، من خلال جمع القرآن الكريم، مواقيت الصلاة، الأذكار، الأدعية، القبلة، الكتب الإسلامية، التلاوات، المحتوى المرئي، والأدوات التعبدية في تجربة واحدة سهلة ومنظمة.

> 🌙 هدف المشروع: جعل الوصول إلى المحتوى الإسلامي الموثوق والأدوات اليومية للعبادة أكثر سهولة.

### English

**Islam App** is a complete Flutter application designed to be a daily companion for Muslims. It brings the Holy Quran, prayer times, azkar, duas, Qibla, Islamic books, recitations, video content, and worship tools together in one organized experience.

> 🌙 Project goal: make trusted Islamic content and daily worship tools easier to access.

## 🚀 تشغيل المشروع

### المتطلبات

- Flutter SDK متوافق مع Dart SDK `^3.7.2`
- Android Studio أو Xcode
- جهاز حقيقي أو محاكي
- إعداد Firebase عند الحاجة إلى ميزات الحساب والمزامنة

### English

- Flutter SDK compatible with Dart SDK `^3.7.2`
- Android Studio or Xcode
- A physical device or emulator
- Firebase configuration when authentication or cloud synchronization is required

### خطوات التشغيل

```bash
# استنساخ المستودع
git clone https://github.com/hozifa460/app_islam.git

# الدخول إلى مجلد المشروع
cd app_islam

# تثبيت الاعتمادات
flutter pub get

# تشغيل التطبيق
flutter run
```

### English

```bash

# Run the application
```
